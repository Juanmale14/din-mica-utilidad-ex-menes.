Configuración de Conexión Google Apps Script 

function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var respuestas = [];
  
  // Salta la fila 0 de encabezados y lee únicamente la Columna 2 (índice 1)
  for (var i = 1; i < data.length; i++) {
    var textoReflexion = data[i][1];
    if (textoReflexion && textoReflexion.toString().trim() !== "") {
      respuestas.push(textoReflexion.toString().trim());
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify(respuestas))
    .setMimeType(ContentService.MimeType.JSON);
}

Instrucciones de la Dinámica

Bienvenido/a a la actividad compartida "¿Para qué sirven los exámenes?".

  1. Abre el formulario enviado por el docente o moderador.
  2. Escribe tu respuesta sincera sobre cuál consideras que es la función principal de los exámenes.
  3. Envía tu respuesta. Esta aparecerá automáticamente organizada en las columnas de esta pantalla.
  4. Utiliza el botón "Cargar / Refrescar" para traer las nuevas aportaciones registradas.
  5. Utiliza el "Modo Proyección" para visualizar en pantalla grande las opiniones por bloques de columnas.
